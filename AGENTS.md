# Agent Address contributor guidelines

Follow [CODE_PRINCIPLES.md](CODE_PRINCIPLES.md) in all code and test changes. In particular: use OO and clear separation of concerns, avoid duplicated logic, report exceptions through the shared error boundary, use braces for JavaScript and TypeScript control blocks, and group semantic phases with deliberate vertical spacing. Keep public API changes backed by Worker/D1 tests. Never deploy to production as part of a draft PR.
